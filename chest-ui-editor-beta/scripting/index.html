4 TRIGGER

Choose how the crafting check runs in-game.

⏱
AUTO INTERVAL
Checks for a valid recipe automatically every few ticks. Simplest option — always watching.
🖱
ITEM DROP (BUTTON)
Fires only when a Button in your UI drops a specific item. Crafts on demand when the player clicks.
ticks
How to set this up: In the Chest UI Editor, add a Button component. Set its action to "Drop one" or "Drop all" and point it at a slot that holds your trigger item. When the player clicks that button, the item is dropped from the entity, and the script detects it and runs the crafting.
